# Créditos

Projeto fictício de portfólio de LS Luccas Souza. A barbearia, os barbeiros, os clientes, os depoimentos, os preços e os contatos são inventados. As pessoas que aparecem nas fotos não têm relação com a marca fictícia, e os nomes dos barbeiros (Diego, Marcos, Felipe e Renan) são apenas rótulos do layout.

## Fotografias

Todas as fotos são de **domínio público (CC0)**: uso comercial liberado, sem atribuição obrigatória. Mesmo assim, a origem de cada uma está registrada abaixo.

**Por que Rawpixel e não Unsplash ou Pexels:** o briefing pedia Unsplash ou Pexels, mas os dois bloqueiam download automatizado com verificação anti-robô, e a API do Unsplash exige uma chave. Com a autorização do autor do projeto, as fotos foram buscadas pela API pública do [Openverse](https://openverse.org) (o buscador de imagens abertas mantido pela WordPress Foundation), filtrando só as licenças CC0 e Public Domain Mark. Todas as escolhidas vêm da coleção de domínio público do [Rawpixel](https://www.rawpixel.com/category/53/public-domain). Foi usada a versão de 1024 px sem marca d'água, recortada e convertida para WebP.

Nenhuma foto mostra pessoa famosa. Foram evitadas imagens com marcas ou logotipos visíveis.
