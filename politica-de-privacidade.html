Política de Privacidade

Como os dados seriam tratados num site real e o que acontece neste projeto demonstrativo.

Projeto fictício. A Lâmina Fina Barbearia não existe. Este site foi desenvolvido para portfólio por LS Luccas Souza e nenhum atendimento real é oferecido. O texto abaixo é um modelo demonstrativo e não substitui orientação jurídica.

Esta Política de Privacidade explica, com base na Lei Geral de Proteção de Dados Pessoais (LGPD, Lei nº 13.709/2018), como um site real de barbearia trataria os dados pessoais dos clientes e como este projeto demonstrativo funciona na prática.

1. Resumo rápido

  • Neste projeto demonstrativo, nenhum dado é enviado ou armazenado em servidor.
  • O agendamento funciona só dentro do seu navegador.
  • O site guarda no localStorage apenas a sua escolha sobre o aviso de cookies e o resumo do último agendamento de demonstração.

2. Quais dados o agendamento coletaria num site real

DadoPara quê
NomeIdentificar o cliente na chegada.
Telefone (WhatsApp)Confirmar, lembrar, remarcar ou cancelar o horário.
Serviço escolhidoReservar o tempo certo na agenda e preparar o atendimento.
Dia, horário e barbeiroOrganizar a agenda da equipe.

Não seriam pedidos dados sensíveis, documentos ou dados de cartão.

3. Finalidade

Os dados seriam usados somente para marcar e gerenciar atendimentos, enviar lembretes do horário e, se você autorizar, avisar sobre novidades e promoções da barbearia.

4. Base legal

  • Execução de contrato (art. 7º, V): para marcar e realizar o serviço que você pediu.
  • Consentimento (art. 7º, I): para mensagens de novidades e promoções, que você pode recusar ou cancelar a qualquer momento.

5. Como funciona neste projeto demonstrativo

Este site não tem servidor de banco de dados, não usa ferramentas de análise e não envia formulários. Quando você confirma um agendamento, o resumo aparece só na sua tela. Para mostrar "Seu último agendamento" quando você voltar, o site grava esse resumo no localStorage do seu próprio navegador, sem nome nem telefone.

Se você recusar no aviso de cookies, o resumo do agendamento não é gravado. Veja os detalhes na Política de Cookies.

6. Compartilhamento

Num site real, os dados seriam compartilhados apenas com o sistema de agenda e o serviço de mensagens usados pela barbearia, na medida necessária para o atendimento, e com autoridades quando exigido por lei. Os dados nunca seriam vendidos.

Neste projeto, não há compartilhamento. O mapa do rodapé é carregado do OpenStreetMap, que recebe dados técnicos da sua conexão, como acontece com qualquer conteúdo externo.

7. Prazo de guarda

Os dados de agendamento seriam mantidos por até 12 meses após o último atendimento, para histórico do cliente, e depois excluídos ou anonimizados, salvo obrigação legal de guarda. Os dados do localStorage ficam no seu navegador até você apagá-los.

8. Seus direitos (art. 18 da LGPD)

Como titular, você pode pedir a qualquer momento:

  • confirmação de que existe tratamento dos seus dados;
  • acesso aos dados;
  • correção de dados incompletos, inexatos ou desatualizados;
  • anonimização, bloqueio ou eliminação de dados desnecessários ou tratados em desacordo com a lei;
  • portabilidade dos dados a outro fornecedor;
  • eliminação dos dados tratados com base no consentimento;
  • informação sobre com quem os dados foram compartilhados;
  • informação sobre a possibilidade de não consentir e suas consequências;
  • revogação do consentimento.

9. Encarregado (DPO)

Canal fictício do encarregado pelo tratamento de dados: privacidade@laminafina.exemplo. Este endereço não recebe mensagens, pois o projeto é demonstrativo.

10. Alterações

Esta política pode ser atualizada. A versão válida é sempre a publicada nesta página.
